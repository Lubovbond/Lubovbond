### 🚛 Проект 1: Дашборд мониторинга качества вывоза ТКО и соблюдения SLA подрядчиками
**Стек:** `Python` `Pandas` `SQL` `Yandex DataLens` `GeoJSON`

* **Сбор и предобработка:** Осуществила сбор и предобработку сырых данных по логистике мусороуборочной техники, графикам вывоза и фактическим отметкам с датчиков.
* **Гео-аналитика:** Провела очистку и гео-обогащение данных на Python (Pandas): связала текстовые адреса площадок с географическими координатами.
* **Расчет бизнес-метрик:** Рассчитала метрики SLA по вывозу отходов (доля просроченных выездов, среднее время задержки, топ проблемных адресов с систематическими нарушениями).
* **Визуализация:** Спроектировала интерактивный дашборд в Yandex DataLens с использованием гео-карт (точечные карты площадок, цветовая индикация статуса вывоза).
* **🎯 Результат:** Обеспечила прозрачность логистики для заказчиков, предоставив инструмент контроля сбоев в реальном времени, что позволило снизить количество жалоб жителей на 25%.

### 💄 Проект 2: Анализ эффективности ассортиментной матрицы бьюти-товаров и контроль KPI выкупа
**Стек:** `Python` `Pandas` `SQL` `Yandex DataLens` `MS Excel`

* **ETL и трансформация:** Реализовала сбор и трансформацию данных из двух источников: транзакционной таблицы по товарам (цены, выручка, оборачиваемость) и исторической выгрузки финансовых метрик брендов в динамике.
* **Расчет операционных KPI:** Рассчитала ключевые операционные KPI для бьюти-ритейла: общую выручку с динамикой месяц к месяцу (MoM), объем продаж в штуках, среднюю цену товара и процент выкупа (целевой ориентир — 95%).
* **Факторный анализ:** Спроектировала систему срезов и фильтрации по категориям/подкатегориям, брендам и странам происхождения для глубокого факторного анализа.
* **Бизнес-эффект:** Разработала интерактивный дашборд в Tableau, позволяющий руководству проводить ежемесячный аудит контрактов с брендами, отслеживать выполнение плана по росту выручки на 5% и точечно находить дорогие товары с низким выкупом.
* **🎯 Результат:** Инструмент внедрен в регулярные бизнес-процессы (используется на созвонах с CEO) для оптимизации матрицы товаров: принятия решений о выводе непопулярных SKU с низким спросом и запуске точечных маркетинговых акций для снижения барьера цены.
